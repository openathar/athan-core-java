# athan-core-java

Public Core SDK (Java/Kotlin) für präzise, offline-fähige Berechnung von
Gebetszeiten, Qibla-Richtung und Hijri-Kalender. Teil der Athar-Plattform
(Sadaqah Jariyah, 100% Open Source) — siehe [openathar](https://github.com/openathar).

MIT/Apache-2.0 lizenziert (final zu entscheiden) — bewusst permissiv, damit
andere Entwickler die Library frei in eigene Projekte einbinden können.
